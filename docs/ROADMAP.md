# Roadmap — Nexus Links

> Quarter-by-quarter product roadmap.

## 2026

### Q2 — Foundation

- [x] Design system: colors, typography, tokens, glass effects
- [x] Landing page: 12-section marketing page
- [x] Authentication UI: login, register, password reset, 2FA
- [x] App shell: sidebar, topbar, command palette, search
- [x] Brand identity: logo, brand guidelines, animations
- [x] Link Studio: 3-panel link creation with preview + AI
- [x] Full interactive prototype: analytics, QR studio, developer hub, workspace, settings, billing

**Milestone:** Complete interactive prototype — investors can spend 30 minutes exploring without noticing no backend.

### Q3 — MVP

- [ ] Fastify server with PostgreSQL + Prisma
- [ ] REST API: link CRUD, auth, user management
- [ ] Link redirect service (sub-50ms)
- [ ] Real analytics collection and dashboard
- [ ] Custom branded domains
- [ ] QR code generation
- [ ] Stripe billing integration
- [ ] Email service (transactional)
- [ ] Docker Compose development environment

**Milestone:** Private beta with 100 users.

### Q4 — Launch

- [ ] Public launch
- [ ] Team workspaces with RBAC
- [ ] Campaign folders and UTM builder
- [ ] CSV/PDF export for analytics
- [ ] API key management
- [ ] Webhook event system
- [ ] Rate limiting and abuse prevention
- [ ] Status page

**Milestone:** Public launch — target 1,000 signups in first month.
